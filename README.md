# PocketBoy

Game-Boy-, Game-Boy-Color- und Game-Boy-Advance-Emulator im Browser, gemacht fürs iPhone.

- Drei Gehäuse: Klassisch, Color, Advance (quer)
- Eigene ROMs (.gb / .gbc / .gba) aus der Dateien-App laden
- Vollbild über „Zum Home-Bildschirm“, Haptik, Pixelraster, Nachzieh-Effekt, Turbo
- Automatische Speicherstände
- `demo.gb`: kleines selbst geschriebenes Testspiel (lizenzfrei)

Emulator-Kern: mGBA über EmulatorJS (wird zur Laufzeit vom CDN geladen).
Hilfe: kleine Schraube unten am Gehäuse antippen.
